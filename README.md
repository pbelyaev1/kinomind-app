# KinoMind — собранное приложение

Здесь лежит только результат сборки: один HTML-файл со всем приложением,
service worker, манифест PWA и отпечаток версии.

Репозиторий нужен как канал доставки обновлений. Сервер приложения
(Cloudflare Worker) раз в пять минут смотрит сюда в `update.json` и,
если отпечаток сборки изменился, забирает свежие файлы.

Ничего секретного здесь нет: токены Кинопоиска и OpenRouter живут
на сервере и в браузер не попадают.

Само приложение: https://kinomind.pbelyaev12.workers.dev
